## English

The listed versions passed local Windows tests with a dedicated server and two independent clients, covering full-catalog downloads and remote animations. These are unofficial experimental alpha builds. See each version’s port document and Release notes for the complete test scope and limits.

Choose the JAR for your exact Minecraft version from the table and install the same file on the server and every client. Releases contain English, French, Simplified Chinese and Japanese instructions, including the verified Windows Java options. Get the original models from the [companion catalog](https://github.com/IsSlashy/Yes-Steve-Model-Repo); model files are unchanged across these ports. This fork's `main` keeps the upstream source snapshot; the current port sources are on the version branches linked above.
